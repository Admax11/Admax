# ADMAX Developer Portfolio

The source code for the ADMAX Developer Portfolio and App Store.

## Live website

https://admax-developer-portfolio-bl4lq9.v2.appdeploy.ai/

## Hosting

The live application remains hosted on AppDeploy. This GitHub repository is a source-code backup and version-control location; pushing code here does not move or change the live deployment.

## Project

- React + TypeScript + Vite frontend
- AppDeploy backend API, authentication, database and storage integration
- Admin account allowlist is configured in the backend source
- App Store listings support search, category filters, cover images, editing and removal

## Development

Use the AppDeploy project environment and its supported SDK packages to build and deploy this application. Do not publish credentials, API keys, or private environment values in this repository.
